# Photo2Video Archive — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## Test before archiving a larger batch

Choose varied images: a screenshot with small text, a detailed photograph and any supported special photo type you use. Compare the archive and restored samples with the source. Record what is preserved and what changes before deciding whether the workflow suits the collection.

## Understand actual space savings

Count the archive video, any retained originals package and any remaining Photos originals. Recently Deleted and iCloud settings can affect when space changes become visible. A smaller video file alone is not the complete storage calculation.

## Restore the right kind of output

Use frame export when an image reconstructed from the video is acceptable. Use the documented originals-package restoration when byte-exact files are needed and the package is present. Keep the archive video and do not assume reinstalling the app will recreate a deleted local package.
