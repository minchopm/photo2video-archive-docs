# Photo2Video Archive — quick start

## Goal

Complete one small, verifiable task before using the workflow for a larger project.

## Before you begin

Use the current product from the official source. Check its device requirements and entitlements; a free download does not necessarily mean every operation is free. The feature table records product-specific limits.

## Steps

1. Start with a small group of non-critical photos that are fully available on the device.

2. Keep a separate backup of important originals before experimenting with archiving.

3. Create the archive and allow the app to verify and save it.

4. Open it again and export a few frames. Compare fine detail, text, orientation and visible metadata.

5. If exact restoration is required, verify the originals-package workflow separately. Do not delete originals or uninstall the app based solely on successful frame export.

## Verify the result

Return to the saved output or record rather than relying only on the preview. Check the specific items described in the steps above. If the result differs, keep the original input and reproduce the issue with a small, non-sensitive example.
