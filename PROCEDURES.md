# Photo2Video Archive — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Qualify an archive before removing anything

### Before you begin

Keep a separate backup and choose a small varied photo batch.

### Steps

1. Include detailed photos and a screenshot with small text.

2. Create and reopen the verified archive.

3. Export sample frames and compare detail, orientation and visible information.

4. If byte-exact files are required, test originals-package restoration separately.

5. Count archive, retained package and remaining Photos originals before interpreting savings.

### Expected result

You know which output is lossy, which originals remain restorable and how storage is used.

### If the result differs

A decoded frame is not byte-exact. The current site says uninstalling removes the local originals package; do not rely on the archive video alone for exact restoration.

## Procedure 2: Choose the restoration path

### Before you begin

Identify whether an image representation or the exact original file is required.

### Steps

1. Open the valid archive and choose a small sample.

2. Use frame export for reconstructed images.

3. Use the documented originals restoration only when the local package exists.

4. Check filenames, dates and special media properties that matter to your use case.

5. Preserve the archive and verified backup before larger changes.

### Expected result

The restored output matches the kind of preservation you need.

### If the result differs

Photos/iCloud synchronization and local package storage are different. Do not transfer assumptions from another PhotoVault product.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
