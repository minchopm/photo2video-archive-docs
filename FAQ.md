# Photo2Video Archive — frequently asked questions

## What should I check when using archive video?

HEVC frame export is lossy; compression varies by input. No fixed savings ratio is promised.

## What should I check when using frame export?

Decoded frames are not byte-exact originals.

## What should I check when using exact restoration?

Deleting the app removes that package. The video alone does not guarantee exact originals or all original media properties.

## What should I check when using selection and storage?

Keeping the originals package also consumes space. Photos iCloud synchronization follows Apple settings.

## Where should I start?

Use the quick-start guide with a small example, verify the saved result, then choose a practical workflow. Avoid beginning with irreplaceable data or an entire production project.

## How do I report a documentation or app problem?

Use the official product support channel for account or purchase issues. A public GitHub issue is suitable for documentation corrections and sanitized reproduction steps. Include the app version, device/OS, expected outcome and actual result; do not attach private data.
